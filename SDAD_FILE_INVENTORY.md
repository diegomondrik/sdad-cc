# SDAD File Inventory
> Updated: 2026-04-30

## Folder Structure

    sdad-kit/
    +-- core/    Platform-agnostic skills and lesson library
    +-- cc/      Claude Code specific files
    +-- web/     Web UI specific files
    +-- diego/   Diego personal edition
    +-- shared/  Cross-platform (User Preferences Snippet)

---

## shared/

  SDAD_USER_PREFERENCES_SNIPPET.md  ->  User Preferences (once per account)
                                        Contains $S1, $S2, $SM, $S1e, $S2e
  SDAD_QA_PROTOCOL.md               ->  Project Knowledge per SDAD project
                                        ($QA code review — CC, Web, Diego)
